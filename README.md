# college-library-system
Состав команды и распределение ролей: в команду проекта входят три человека. Касимов Дмитрий (Team Lead) — выполняет роль тимлида и архитектора базы данных: координирует общую разработку, проектирует схему таблиц в СУБД Access, проводит код-ревью, одобряет пулл-реквесты и выполняет финальное слияние в ветку develop. Петухов Кирилл (Backend-разработчик / Тестировщик) — реализует подключение к Access через драйвер pyodbc, разрабатывает API авторизации и маршруты каталога, проверяет корректность ответов сервера и ведет историю изменений проекта в CHANGELOG.md. Ложкин Сергей (Frontend-разработчик / QA) — разрабатывает пользовательский интерфейс на React, настраивает динамическую фильтрацию книг, модальные окна бронирования и составляет тест-кейсы для ручной проверки клиентской части.
